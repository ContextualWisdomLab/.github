💡 What: `scripts/ci/opencode_review_normalize_output.py`의 `runtime_tool_slug` 함수에서 화이트스페이스를 정규화할 때 사용하던 정규표현식(`re.sub(r"\s+", "-", ...)`)을 파이썬 네이티브 메서드인 `"-".join(text.split())`으로 대체했습니다.

🎯 Why: 반복적으로 호출되는 문자열 처리 함수 내에서 매번 정규표현식을 파싱하고 평가하는 것은 불필요한 캐시 룩업과 실행 오버헤드를 유발합니다. C 언어 수준에서 최적화된 네이티브 문자열 메서드 조합을 사용하면 정규표현식 엔진의 오버헤드를 완전히 피할 수 있습니다.

📊 Impact: 대용량 리뷰 텍스트를 처리할 때 정규표현식 실행 비용을 제거하여 런타임 속도를 향상시키고 CPU 소모를 줄입니다.

🔬 Measurement: 수정 전후에 대해 Python 내장 모듈(`timeit`)로 화이트스페이스 분리 및 결합 속도를 벤치마크 테스트해 성능 개선을 확인할 수 있습니다. 관련 CI 테스트(`test_opencode_fact_gate_contract.sh`, `pytest` 등)가 100% 성공하며 기능 동일성을 증명합니다.
