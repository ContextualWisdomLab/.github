🎯 What:
`scripts/ci/sandboxed_web_e2e.py`의 `wait_for_url` 함수에서 `--backend-ready-url` 또는 `--frontend-ready-url` 파라미터로 전달된 URL을 검증하는 로직에 SSRF(Server-Side Request Forgery) 취약점이 존재하여 이를 수정했습니다.

⚠️ Risk:
기존 로직은 URL이 `http://` 또는 `https://`로 시작하는지만 검증하고, 호스트명(hostname)을 검증하지 않았습니다. 이로 인해 악의적인 사용자가 환경변수나 파라미터를 조작하여 `http://169.254.169.254`나 내부 네트워크 주소로 요청을 보내어 내부 시스템을 스캐닝하거나 민감한 정보를 탈취할 위험(SSRF)이 있습니다.

🛡️ Solution:
`urllib.parse.urlparse`를 활용하여 대상 URL의 호스트명이 로컬 루프백 주소(`localhost`, `127.0.0.1`, `::1`)인지 명시적으로 검증하는 로직을 추가했습니다. 지정된 로컬 호스트명이 아닌 경우 `ValueError`를 발생시키며 요청을 차단합니다. 또한 이 검증 로직이 정상적으로 작동하는지 확인하기 위해 `tests/test_sandboxed_web_e2e.py`에 테스트 케이스를 추가했습니다.
