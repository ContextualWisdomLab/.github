# CWL Integration Contracts

- [CWL Ecosystem Integration Contract v1](CWL_ECOSYSTEM_INTEGRATION_CONTRACT.md) defines shared transport, event, command, temporal, provenance, privacy, and compatibility semantics.
- [CWL Repository Responsibility Catalogue v1](CWL_REPOSITORY_RESPONSIBILITY_CATALOG.md) defines repository ownership, capability, purpose-bound data flow, maturity, and customer next actions.

The responsibility catalogue reuses the event and command envelopes; it does not create a competing transport schema. Leaf repositories retain domain semantics and operational authority.
